# Trino + PostgreSQL + MySQL + Iceberg Data Integration Project

Проект представляет собой решение для федеративной обработки данных с использованием Trino в качестве SQL-движка, подключенного к нескольким источникам данных (PostgreSQL, MySQL) и сохранения агрегированных результатов в Apache Iceberg с поддержкой версионности через Nessie.

## Особенности

- **Мульти-источниковые запросы**: Единые SQL-запросы к PostgreSQL и MySQL через Trino
- **Современное хранилище**: Apache Iceberg с версионностью через Nessie
- **Визуализация**: Готовые примеры графиков с использованием matplotlib
- **Контейнеризация**: Полная изоляция через Docker Compose
- **Учебный проект**: Соответствует требованиям итоговой домашней работы

## Документация

| Уровень | Требование | Статус |
|---------|------------|--------|
| **1. Подключения** | Trino + PostgreSQL + MySQL |
| **2. Агрегация** | 2+ SQL запроса, pandas DataFrame |
| **3. Визуализация** | 2+ графика с оформлением |
| **4. Iceberg** | Схема + таблица + проверка |
